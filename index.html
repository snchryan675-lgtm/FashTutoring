How to install

  1. Download the installerSave FashTutoring-Setup.exe to your computer.
  2. Open itDouble-click the file and choose where to install the app.
  3. Launch Fash TutoringUse the desktop shortcut or the Start menu.

Using the zip instead

  1. Extract the whole zipRight-click it and choose Extract All. Don't run it from inside the zip.
  2. Run Fash Tutoring.exeKeep the folder together and put it anywhere you like.

Windows shows a blue warning screen

The app isn't code-signed, so Windows SmartScreen may say it protected your PC. Choose More info, then Run anyway.

Updating

Download the newest installer and run it over the old version. Your accounts and settings stay in place.

Removing the app

Open Settings, then Apps, find Fash Tutoring and choose Uninstall. If you used the zip, delete the folder.
